# Prompt Patterns Reference

Optimized prompt templates for every post type category. Each pattern uses `{variable}` placeholders that get filled from the brand config and user input.

---

## How Prompts Are Built

Every prompt follows this structure:

```
[Visual description] + [Brand style injection] + [Platform format] + [Text overlay instructions]
```

The brand's `style_keywords`, `tone`, and `colors` are automatically injected. These templates handle the visual description and text overlay parts.

---

## 1. Promotional Posts

For sales, discounts, product launches, and limited-time offers.

### Sale / Discount

```
A {tone} social media post for {brand_name} announcing {discount_amount} off {product_or_category}.
Bold "{headline_text}" as the main text element.
Feature {product_visual_description} as the focal point.
Use {primary} and {accent} as dominant colors with {background} base.
Include a clear call-to-action area reading "{cta_text}".
{style_keywords joined as comma-separated descriptors}.
```

**Tips:**
- Lead with the discount number -- make it the largest visual element.
- Use `accent` color for the discount percentage to create urgency.
- Keep headline to 4 words or fewer. "50% OFF EVERYTHING" beats "Get fifty percent off all our products."
- Add urgency language: "Today only", "Ends midnight", "24 hours left."

**Best references:** Previous sale posts, e-commerce brand posts, Black Friday campaigns.

### Product Launch

```
A {tone} product launch announcement for {brand_name}.
Hero shot of {product_description} centered in the composition.
"{launch_headline}" as bold headline text in {heading_font}.
Subtle tagline "{tagline_or_subtext}" below the headline.
Color palette: {primary} headline, {accent} highlights, {background} base.
Premium, aspirational feel. {style_keywords}.
```

**Tips:**
- Single product, clean background. Let the product breathe.
- "New" or "Introducing" as a small chip/badge above the headline works well.
- Avoid cluttered compositions -- launch posts should feel elevated and focused.

**Best references:** Apple product shots, premium unboxing aesthetics, tech launch visuals.

### Bundle / Package Deal

```
A {tone} social media graphic for {brand_name} promoting a bundle deal.
Show {number_of_items} items arranged in a {layout_style} composition: {item_descriptions}.
"{bundle_headline}" as the headline with price "{price_text}" prominently displayed.
{accent} color for the price, {primary} for the headline, {background} base.
{style_keywords}.
```

**Tips:**
- Arrange items in a grid or layered stack so each is visible.
- Crossed-out original price + new bundle price creates strong value perception.
- Use "Save {amount}" instead of listing the math.

**Best references:** Subscription box visuals, meal kit presentations, SaaS pricing cards.

## 2. Informational Posts

For tips, facts, how-tos, and educational content.

### Tip / Hack

```
A {tone} educational post for {brand_name} sharing a {topic} tip.
Clean layout with "{tip_headline}" as the main text.
{visual_metaphor_or_illustration} as the supporting visual element.
Numbered or bulleted layout if multiple tips: {tip_list}.
{primary} headline, {text} body text, {background} base, {accent} for emphasis markers.
{style_keywords}. Easy to read, high contrast text.
```

**Tips:**
- One tip per post performs better than tip dumps. Save lists for carousels.
- Use icons or simple illustrations next to each point.
- "Did you know?" or "Pro tip:" as a header chip drives engagement.
- Keep body text at 16px equivalent minimum for readability.

**Best references:** Infographic-style posts, educational Instagram accounts, Canva tip templates.

### Fact / Statistic

```
A {tone} data-driven post for {brand_name} highlighting a key statistic.
Large, bold "{stat_number}" as the hero element in {accent} color.
Supporting context "{stat_context}" in smaller {text} colored text below.
{data_visualization_or_icon} as a subtle background or supporting element.
{background} base, minimal layout. {style_keywords}.
Source attribution "{source}" in small text at bottom.
```

**Tips:**
- The number IS the post. Make it enormous -- 60%+ of the visual space.
- Round numbers when possible. "87%" is more impactful than "86.7%."
- Always cite the source. Credibility drives shares.
- Use a single accent color for the stat, muted everything else.

**Best references:** Data visualization posts, research report covers, annual report graphics.

### How-To / Tutorial

```
A {tone} step-by-step tutorial post for {brand_name}.
Title: "{tutorial_title}" in {heading_font}.
{number_of_steps} steps laid out in a clear visual sequence:
{step_descriptions_with_numbers}.
Each step has an icon or mini-illustration.
{primary} for step numbers, {text} for descriptions, {accent} for arrows/connectors.
{background} base. {style_keywords}.
```

**Tips:**
- 3-5 steps maximum for a single post. More than that needs a carousel.
- Numbered steps with clear visual hierarchy (number > action > detail).
- Use directional cues (arrows, lines, numbering) to guide the eye.
- Step 1 should be the easiest -- lower the barrier to entry.

**Best references:** Recipe cards, DIY tutorials, onboarding flows.

## 3. Announcement Posts

For events, feature updates, company news, and milestones.

### Event Announcement

```
A {tone} event announcement for {brand_name}.
"{event_name}" as the bold headline in {primary} color.
Key details clearly displayed: {date}, {time}, {location_or_platform}.
{event_visual_theme} as the background or supporting imagery.
{accent} color for date/time highlights, {background} base.
{style_keywords}. Professional yet inviting.
```

**Tips:**
- Date and time must be instantly readable -- never buried in body text.
- Use a visual hierarchy: Event name > Date/Time > Location > Description.
- For virtual events, include the platform icon (Zoom, Google Meet, etc.).
- "Save the date" or "You're invited" as a small label above the event name.

**Best references:** Conference posters, meetup graphics, webinar invitations.

### Feature / Product Update

```
A {tone} feature update post for {brand_name}.
"{feature_name}" as the headline with a "NEW" or "UPDATE" badge in {accent}.
{feature_visual_description} showing the feature in action.
Brief value proposition "{value_prop}" as supporting text.
{primary} headline, {secondary} for UI elements, {background} base.
{style_keywords}. Clean, tech-forward.
```

**Tips:**
- Show, don't tell. A screenshot or UI mockup of the feature beats abstract graphics.
- "New" badge in accent color immediately signals what this post is about.
- One feature per post. Don't bundle updates unless it's a changelog carousel.
- Lead with the benefit ("Save 2 hours/week") not the feature name ("Batch Export v2.1").

**Best references:** App update screenshots, SaaS changelogs, product hunt launch graphics.

### Milestone / Achievement

```
A {tone} celebration post for {brand_name} marking {milestone_description}.
Large, celebratory "{milestone_number}" or "{milestone_text}" as the hero element.
Subtle celebratory elements (confetti, stars, glow) that match the brand aesthetic.
"{thank_you_message}" as supporting text.
{accent} for the milestone, {primary} for supporting text, {background} base.
{style_keywords}. Proud but not boastful.
```

**Tips:**
- Milestones are about the community, not the company. "YOU helped us reach 10K" beats "We hit 10K."
- Use round numbers or let the exact number tell the story ("10,000" vs "10K" depends on tone).
- Subtle celebration -- confetti and fireworks should match brand style, not look like a stock template.

**Best references:** Follower milestone posts, anniversary graphics, year-in-review cards.

## 4. Engagement Posts

For quotes, polls, questions, and community interaction.

### Quote

```
A {tone} quote post for {brand_name}.
"{quote_text}" as the centerpiece in elegant {heading_font} typography.
Attribution "-- {author_name}" below the quote in {text} color.
{decorative_element} such as quotation marks, a subtle pattern, or brand-colored border.
{background} base with {primary} quote text. Minimal, typography-focused.
{style_keywords}.
```

**Tips:**
- The quote IS the design. Typography does all the heavy lifting.
- Large decorative quotation marks (in `accent` color, low opacity) add visual interest without clutter.
- Keep quotes under 20 words for single-image posts. Longer quotes need carousel treatment.
- Attribute the source always. Unattributed quotes feel cheap.

**Best references:** Minimalist quote accounts, book cover typography, editorial layouts.

### Poll / This or That

```
A {tone} engagement poll post for {brand_name}.
"{poll_question}" as the headline in {primary}.
Two options displayed side by side: "{option_a}" vs "{option_b}".
Split-screen or versus layout with {primary} on one side and {accent} on the other.
"VS" or divider element between the options.
{background} base. {style_keywords}. Fun, interactive feel.
```

**Tips:**
- Both options should be visually equal in weight -- no bias toward one side.
- Use "This or That?", "A or B?", or "Which one?" as a small header chip.
- Bold, contrasting colors for each side create strong visual tension.
- The question matters more than the design -- pick genuinely debatable topics.

**Best references:** Instagram poll stickers, "would you rather" posts, comparison graphics.

### Question / Conversation Starter

```
A {tone} engagement post for {brand_name} asking the audience a question.
"{question_text}" as large, centered text in {primary} color.
{supporting_visual_or_icon} as a subtle background element.
Minimal design -- the question is the entire focus.
{background} base, {accent} for a subtle border or underline emphasis.
{style_keywords}. Open, inviting, conversational.
```

**Tips:**
- One question only. Multiple questions dilute engagement.
- Open-ended questions ("What's your biggest challenge with X?") outperform yes/no questions.
- Add "Tell us in the comments" or a comment icon to explicitly invite responses.
- Questions that validate the audience's experience drive the highest engagement.

**Best references:** Twitter/X engagement posts, community discussion starters, AMA graphics.

## 5. Story Posts

For Instagram/TikTok stories, reels covers, and ephemeral vertical content.

### Instagram / TikTok Story

```
A {tone} vertical story graphic (9:16 aspect ratio) for {brand_name}.
"{story_headline}" as large, bold text positioned in the center-upper third.
{story_visual_description} filling the frame.
Interactive element placeholder: {interactive_type} (poll sticker zone, question box, swipe-up area).
{primary} text with {accent} interactive elements on {background}.
{style_keywords}. Mobile-first, full-bleed, immersive.
```

**Tips:**
- Safe zones: Keep text within the center 80% of the frame. Top and bottom 10% get clipped by UI.
- Stories are consumed fast -- 3 seconds to capture attention. Lead with the hook.
- Leave space for interactive stickers (polls, questions, sliders) in the lower third.
- Use 9:16 (1080x1920) always. Never letterbox a square post into a story.

**Best references:** Brand Instagram stories, story ad templates, Snapchat discover layouts.

### Reel / Short Video Cover

```
A {tone} reel cover image for {brand_name}.
"{reel_title}" as bold, readable text in {heading_font}.
{thumbnail_visual} as the background -- high energy, mid-action, or intriguing.
Ensure text is readable over the image (text shadow, overlay, or solid text block).
{primary} text, semi-transparent {secondary} overlay if needed.
{style_keywords}. Vertical 9:16, thumb-stopping.
```

**Tips:**
- The cover is a thumbnail on the grid -- it must read at small sizes.
- 3-5 words maximum for the title. If it doesn't fit in a glance, it's too long.
- Consistent cover style across all reels builds a recognizable grid aesthetic.
- Face + text combination gets the highest click-through.

**Best references:** YouTube Shorts thumbnails, TikTok cover images, podcast episode art.

### Multi-Slide Story Sequence

```
Slide {slide_number} of {total_slides} in a {tone} story sequence for {brand_name}.
This slide: "{slide_content}" with {slide_visual}.
Consistent style across all slides: {primary} headlines, {background} base, {accent} highlights.
Progress indicator or slide number visible.
Visual continuity with previous/next slides through {continuity_element}.
{style_keywords}. 9:16, swipe-friendly.
```

**Tips:**
- First slide is the hook. Last slide is the CTA. Middle slides deliver value.
- Visual continuity (same background, color progression, or animation direction) keeps people swiping.
- 3-7 slides is the sweet spot. Under 3 feels incomplete. Over 7 loses attention.
- Add a progress bar or "1/5" indicator so viewers know how much is left.

**Best references:** Instagram carousel stories, educational story sequences, brand storytelling.

## General Prompt Tips

1. **Be specific about text placement.** "Bold headline in the top third" beats "add some text."
2. **Name colors by hex, not by name.** `#6C3BF5` is unambiguous; "purple" is not.
3. **Describe the composition.** "Centered product with text above" gives the model spatial guidance.
4. **Include style_keywords in every prompt.** They're the consistency glue across all posts.
5. **Reference images beat descriptions.** When a reference image exists in `brand-kit/reference/`, always include it -- it's worth a thousand words of prompt.
6. **Less text = better results.** AI image models struggle with complex text. Keep on-image text to headlines and short phrases. Long copy goes in the caption.
7. **Specify what NOT to include.** "No stock photo feel", "no generic gradients", "no clipart" helps avoid common AI pitfalls.
